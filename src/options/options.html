DOCUMENTAÇÃO PRÁTICA

Como Funciona o TextSwitch

⚡

1. Disparo de Atalhos

O TextSwitch monitora a digitação nos campos de texto da página web. Quando você digita um atalho cadastrado e pressiona a tecla disparadora, ele é substituído instantaneamente.

Gatilhos suportados:
Espaço Enter Tab
Dica: Inicie seus atalhos com / (ex: /ola, /pix, /suporte) para evitar disparos acidentais durante a digitação comum.
📅

2. Variáveis Automáticas de Data e Hora

Você pode inserir marcadores no texto que são resolvidos no exato milissegundo em que o atalho é expandido:

  • {data} — Insere a data atual (ex: 19/11/2026 ou 2026-11-19).
  • {hora} — Insere o horário atual (ex: 14:30 ou 14:30:45).
O formato de exibição da data e hora pode ser ajustado individualmente em cada template no editor.
🧩

3. Formulários Dinâmicos Interativos & Listas de Opções

O TextSwitch oferece um construtor integrado de campos dinâmicos. Quando você dispara um template contendo esses marcadores, uma janela modal leve em Shadow DOM surge na página para você preencher os dados antes da inserção:

Menu de Opções (Dropdown) {formmenu: Opção A; Opção B; Opção C; name=Turno}

Exibe um menu suspenso para escolher entre alternativas predefinidas.

Campo de Texto Curto {formtext: Nome do Cliente}

Campo de linha única para preenchimento de nomes, códigos ou valores.

Parágrafo / Multilinha {formparagraph: Observações do Chamado}

Área de texto para comentários detalhados ou laudos técnicos.

Seletor de Data {formdate: DD/MM/YYYY}

Abre um calendário nativo para escolher uma data personalizada.

🔄

4. Importação e Exportação sem Bloqueios

Você é o único dono dos seus dados. Você pode fazer backup a qualquer momento e migrar facilmente de outras ferramentas:

✓ Formato Text Blaze (JSON exportado com pastas e snippets)
✓ Formato Nativo TextSwitch (JSON com versionamento)
✓ Listas Simples de Objetos JSON ([ { shortcut, text } ])
✓ Dicionários Chave-Valor ({ "/atalho": "Texto" })
TRANSPARÊNCIA TOTAL

Privacidade, Arquitetura Local & Open Source

🏠

100% Local no seu Navegador

O TextSwitch não possui backend, banco de dados na nuvem ou servidores intermediários. Todos os templates, atalhos e configurações ficam gravados diretamente no armazenamento nativo do seu navegador através da API chrome.storage.local.

Nenhum texto digitado ou snippet salvo sai do seu dispositivo. Funciona até mesmo com a internet desligada.
📦

Zero Dependências Externas

O projeto foi construído do zero utilizando exclusivamente JavaScript Vanilla puro e APIs padrão dos navegadores Web (W3C / Manifest V3). Não utiliza frameworks pesados, pacotes npm desnecessários ou bibliotecas externas de terceiros.

Máxima velocidade de execução, uso ínfimo de memória RAM e imunidade contra ataques de supply chain em pacotes externos.
📖

Código Aberto (Open Source)

O TextSwitch é software livre sob licença permissiva MIT. Seu código-fonte é 100% aberto, transparente e auditável por qualquer desenvolvedor ou equipe de segurança.

Sem versões "Pro" pagas, sem assinaturas recorrentes, sem bloqueio de quantidade de snippets e sem anúncios.
🛡️

Privacidade por Design (Zero Telemetria)

Diferente de muitas extensões comerciais que coletam métricas de digitação, telemetria analítica ou histórico de uso, o TextSwitch tem zero rastreadores:

  • ❌ Sem Google Analytics, Mixpanel ou trackers de terceiros.
  • ❌ Sem envio de logs de erros para a nuvem.
  • ❌ Sem necessidade de login, conta ou e-mail para utilizar.
  • ✓ Permissões mínimas no manifesto (apenas storage).
